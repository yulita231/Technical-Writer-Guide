# Technical Writer Intern Starter Guide (Interactive Portal)

Portal panduan interaktif modern, lengkap, dan siap pakai untuk **Technical Writer Intern**.

## 🚀 Fitur Unggulan

1. **🎨 Desain Modern & Responsif**:
   - Dukungan **Dark Mode & Light Mode** otomatis tersimpan di `localStorage`.
   - Glassmorphism header, card hover effect, tipografi *Plus Jakarta Sans* & *JetBrains Mono*.
   - Banner ilustrasi 3D modern (*hero.jpg*).
   - Sidebar navigasi pintar dengan ScrollSpy & progress bar.

2. **⚡ Pipeline Workflow 7 Tahap Interaktif**:
   - Visualisasi tahapan kerja dari *Task Masuk* hingga *Finalisasi Dokumen*.
   - Detail interaktif per tahap lengkap dengan pro-tips dan action items.

3. **💬 Simulator Komunikasi Tim (Generator Pesan)**:
   - Template pesan siap kirim untuk *Klarifikasi Teknis*, *Follow-up Review*, dan *Eskalasi Blocker*.
   - Input dinamis dengan format pesan instan dan tombol 1-klik salin (*copy-to-clipboard*).

4. **🏷️ Generator Penamaan File & Versioning**:
   - Otomatis menghasilkan nama file sesuai standar tim: `[Jenis]_[Project]_v[X.Y].docx`.

5. **✅ Interactive Checklists (Daily & Final)**:
   - Checklist harian (6 poin) dan Checklist Final Sebelum Submit (6 poin).
   - Status centang tersimpan otomatis di `localStorage`.
   - Indikator kemajuan real-time di sidebar.

6. **📋 Template Dokumen Resmi (Siap Salin)**:
   - **Template MoM** (Minutes of Meeting)
   - **Template SOP** (Standard Operating Procedure)
   - **Template User Guide** (Manual Pengguna)
   - Dilengkapi tombol 1-klik salin dengan notifikasi toast.

7. **🔍 Modal Pencarian Instan (Ctrl + K)**:
   - Pencarian cepat di seluruh 12 modul panduan dengan navigasi langsung.

8. **🖨️ Export / Print PDF Ready**:
   - CSS cetak khusus untuk mencetak buku panduan resmi ke PDF.
